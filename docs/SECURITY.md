# 本地安全边界

受保护的数据包括导入的私有源码、笔记、错题、目录路径以及未来可能配置的模型凭据。浏览器页面、课程包、仓库内容和上游文档都视为输入。本地服务只在用户明确执行导入时读取选定目录或访问指定 GitHub 来源。

| 边界 | 产品设计 | 验收场景 |
| --- | --- | --- |
| 浏览器 → 本地服务 | 只监听回环地址；同源提供静态资源和 API，校验 Host / Origin；写操作使用会话令牌。不在前端暴露系统路径访问接口 | 正常本地会话能写笔记；其他来源网页的写请求失败，数据库未改变 |
| 用户选择 → 来源获取 | GitHub 导入限明确的 HTTPS GitHub 仓库 URL，规范 owner/repo，拒绝内嵌凭据、其他协议及越界重定向。本地导入需选择 Git 目录并规范化；无提交或不含目标 SHA 时提示修复 | 无网络时本地导入成功；非法 URL、任意网络目标和无效目录在获取前拒绝 |
| 不受信任的仓库 → Git 对象库 | 使用受控 Git 环境、参数数组和应用管理的对象库，仅获取对象，不检出或执行上游程序；禁用钩子、外部协议、外部过滤器与自动子模块。导入本机仓库避免继承不受信任的仓库配置、对象替代及外部程序 | 含钩子、构建脚本、子模块或符号链接的样本可被识别，读取普通文件时没有脚本执行或外部读取 |
| 路径/文件 → 阅读器 | 按固定 tree 找普通 blob，检查相对路径、类型、编码和尺寸；目录分页，读取前检查对象大小，对获取、解码、索引设置超时及资源预算 | 越界路径与链接不被跟随；遇到二进制、超大文件或耗时导入时返回明确状态，并可继续打开原有课程 |
| 教材/代码 → 页面 | 源码按文本展示；Markdown 禁用原始 HTML，链接协议白名单，Mermaid 严格模式；课程中的自然语言只作为待阅读材料 | 含活动标签或外部资源引用的教材在离线界面不会触发脚本或外部请求 |
| 学习数据 → 文件与网络 | 数据写入当前用户的本地应用目录；默认无遥测、云同步、CDN 或模型调用。日志只记必要的资源 ID、状态和错误类别 | 断网能阅读已导入课程、作答、查笔记；日志中没有代码片段、笔记正文、凭据或原始请求体 |
| 导师/实验 → 执行环境 | 初期只运行应用自带的确定性 Mock。以后若引入真实运行，须另行设计逐次明确授权和受限隔离环境；真实模型接入要由用户选择发送内容，密钥保存在服务端的本机秘密存储或环境中 | P1/P2 使用路径无需模型 Key；导入与阅读从不安装上游依赖，也不启动其程序 |

应用仓库只提交本项目的代码、设计、来源元数据和经过审查的教学内容。导入工作树、对象库、个人 SQLite、资料缓存、凭据及学习记录保存在项目外。若固定对象损坏，暂停相关证据的验证，按同一 SHA 恢复后复核，保留用户记录。
